AI Usage Buddy プライバシーポリシー

施行日：2026年11月11日

運営者

PUREROAST&BREW, LIMITED LIABILITY COMPANY（以下「運営者」）が、macOS アプリ「AI Usage Buddy」（以下「本アプリ」）を提供します。本ポリシーは、本アプリが扱う情報について説明します。

運営者によるデータの収集

運営者は、本アプリを通じて利用者の情報を収集・受信しません。運営者は、本アプリのために独自のサーバーを運用しておらず、本アプリに広告配信、アプリ内課金、独自の解析機能は実装していません。

ただし、後述のとおり本アプリに同梱された OpenAI の Codex app-server（以下「同梱ヘルパー」）は OpenAI のサーバーと通信します。この通信の内容は運営者ではなく OpenAI が扱います。

本アプリが端末内に保存する情報

次の情報は、お使いの Mac 上の本アプリの sandbox コンテナ内（Application Support 配下）に保存されます。

  • 設定：選択中のアカウント、表示する利用枠、通知の設定、言語、更新間隔、ログイン時起動、ショートカットなど。
  • アカウント情報：アカウントの識別子、表示名、公式連携から取得したメールアドレスやプラン種別（取得できた場合）。
  • 利用枠のスナップショット：5 時間枠と週間枠の残量、リセット時刻、取得時刻、取得状態、手動補正値、通知済みの記録。

認証情報（ログイン状態）の管理は同梱ヘルパーが行います。本アプリは、macOS の Keychain への保存を指定して同梱ヘルパーを起動しますが、実際に Keychain へどのように保存されているかを運営者が直接確認したわけではありません。本アプリ自身はパスワードや認証トークンを読み取りません。

一律の保存期間は定めていません。保存した情報は、後述の削除操作を行うか、アプリを削除するまで端末内に残ります。

OpenAI との通信

利用者がアカウントの接続を開始すると、同梱ヘルパーが OpenAI の公式ログイン、アカウント情報の取得、利用枠の取得を行います。ログイン時には、認証用の URL が既定のブラウザで開かれ、OpenAI のサイトと通信します。

同梱ヘルパーは、これらのほかにも OpenAI のサーバーと通信する場合があります。通信の全内容、OpenAI 側での保存期間や利用目的は、運営者では確定できていません。OpenAI による情報の取扱いについては、OpenAI のプライバシーポリシーをご確認ください。

本アプリは、同梱ヘルパーの通信を無効化する設定（解析機能やテレメトリの無効化など）を指定して起動しますが、これはあらゆる通信が行われないことを保証するものではありません。

サンプルデータ表示

アカウントを接続せずに画面を試せる「サンプルデータ」表示では、固定の架空データを画面に表示するだけで、通信、同梱ヘルパーの起動、認証、データの保存、実際の通知は行いません。表示中の数値は実際の利用状況ではありません。終了または再起動すると通常の状態に戻ります。

macOS の通知とログイン時起動

通知を有効にして macOS の許可を与えた場合、残量が少なくなったときに、アカウントの表示名、残量、しきい値を含む通知を macOS に依頼して表示します。ログイン時起動は、利用者が明示的に有効にした場合にだけ登録され、有効な場合は macOS へのログイン後に本アプリが起動して利用枠の更新を試みます。

アカウントの削除

本アプリでアカウントの接続を削除すると、本アプリは同梱ヘルパーに公式のログアウトを依頼し、成功とヘルパーの停止を確認してから、端末内の管理用ホームフォルダーとアカウント登録、利用枠情報、補正値、関連する設定の削除を試みます。ログアウトなどの途中の手順が失敗した場合は、端末内の削除を開始せず、情報を保持してエラーを表示します。

次の点にご注意ください。

  • この操作は OpenAI アカウント自体を削除するものではありません。
  • OpenAI 側の認証が無効になること（失効）を保証するものではありません。
  • ファイル削除や保存の更新に失敗すると、一部の情報だけが削除される場合があります。
  • 管理用ホームフォルダーの外にある作業用・一時フォルダーは、この削除の対象外です。
  • アプリをアンインストールした後の sandbox コンテナの扱いについて、自動的に削除されることは保証できません。

更新確認とサポートリンク

App Store 版の本アプリは、更新の確認のための通信を行いません。設定画面のサポートリンクは、利用者がクリックしたときにだけ外部ブラウザで GitHub Issues を開きます。

本ページやサポートページは GitHub Pages で提供されています。ページを閲覧すると、GitHub はサインインの有無にかかわらず、セキュリティ目的で閲覧者の IP アドレスを記録・保存します。詳細は GitHub の一般プライバシー声明をご確認ください。これは Web ページ閲覧時の GitHub 側の処理であり、本アプリの動作とは別です。GitHub Issues に投稿した内容は、GitHub 上で公開される場合があります。個人情報や認証情報は投稿しないでください。

本アプリは子どもを対象としておらず、運営者は子どもから意図的に個人情報を収集しません。
